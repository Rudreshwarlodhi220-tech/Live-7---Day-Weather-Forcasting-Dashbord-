# Live-7---Day-Weather-Forcasting-Dashbord-
An interactive Power BI dashboard for live weather analysis and 7-day forecasting across 5 cities using Weather API, Power Query, and DAX.
# 🌦️ Live 7-Day Weather Forecasting Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard that uses Weather API data to analyze current weather conditions and forecast weather trends for the next 7 days across 5 cities.

The dashboard helps users explore weather information through interactive city slicers, KPI cards, and forecast visualizations.

## 🎯 Project Objectives

* Analyze current weather conditions across multiple cities.
* Explore 7-day weather forecast data.
* Build an interactive dashboard using Microsoft Power BI.
* Present weather information in an easy-to-understand visual format.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Weather API

## 📊 Key Features

* **Multi-City Analysis:** Explore weather information for 5 cities.
* **7-Day Forecast:** Analyze upcoming weather trends.
* **Interactive Slicers:** Filter dashboard information by city.
* **KPI Cards:** Display key weather indicators.
* **Weather Visualizations:** Present forecast information through interactive charts.

## 🔄 Data Workflow

1. Retrieved weather data from a Weather API.
2. Imported the data into Power BI.
3. Transformed and prepared the data using Power Query.
4. Used DAX where required for calculations.
5. Created interactive visualizations and KPI cards.
6. Designed the dashboard for multi-city weather analysis.
